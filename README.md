### Market Data

#### Feeds

1. Разработка коннекторов к API фидам
- T-invest
- ALOR
- ByBit

2. Обобщенные контракты и модели данных для сущностей
- OrderBook
- MarketTrade

#### Algos

1. Генератор синтетических данных для LOB и trades
2. Потоковые алгоритмы и статистики (индикаторы)
	- мгновенныые
	- оконные
	- експоненциальные
	- процизводные от других индикаторов
3. Препроцессинг и постпроцессинг данных
	- очистка
	- заполнение пропусков
	- стандартизация, нормализация, масштабирование
	- детектирование аномалий

#### Processing

1. Объединение алгоритмов в вычислительный граф - disruptor
2. Генерация векторов признаков и их объединение в тензор
3. Хранилище тензоров (Redis, MS Fast)


### Research

- стандартизация, нормализация, масштабирование
- исследовательский анализ данных (Python)
- корреляции и ковариации (T, T-1)
- снижение размерности (PCA?)
- выявление ключевых признаков для генерации сигналов обучения моделей
- генератор сингалов для торговли

### Strategy

1. Система упрвления ордерами и позициями - Risk Engine: Signal -> Order
2. Execution Engine: Order -> Trades -> Positions
3. Расчет текущего состояния портфеля и позиций (PNL) 
4. Формирование вектора признаков по ордерам, портфелям и открытым позициям (state vector)
5. Учет вектора состояния в анализе тензора при формировании торговых сигналов 

### DRL models

1. Базовые принциы RL
2. HMM как простой пример 
3. Atary Games как сложный пример  
4. Создание среды обучения на базе gym
5. Формирование функции вознаграждения
6. Обучение агентов - метрики качества
7. Формирование конвеера и мультиагентный подход
