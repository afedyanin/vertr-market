# vertr-market

Сервис сбора и обработки рыночных данных.

## Сервис выполняет функции
 
### Cбор финансовых данных из разных источников 

Подключение к стриминговым сервисам по протоколам gRPC, WebSocket:
- T-Invest
- АЛОР
- MOEX
- ByBit
- Binance

Типы получаемых рыночных данных:
- обезличенные сделки (trades)
- стаканы (limit order books)
- открытый интерес по фьючерсам (open interest)

Каждый тип рыночных данных по каждому инструменту имеет фиксированный идентификатор.
Этот инденификатор (int) является индексом в векторе (массиве) рыночных данных.

### Генерация снапшота рынка на заданном интервале времени

Интервал генерации снапшота задается в конфиге значениями от 100мс до 10с.
Снапшот формируется в виде объекта MarketDataEvent, который содержит в себе вектор (массив) рыночных данных фиксированного размера на момент генерации снапшота.

### Обработка значений рыночных данных и формирование рыночных индикаторов

Снапшот рыночных значений поступает на вход пайплайна, реализованного через паттерн Disruptor.
Набор хендлеров в Disruptor вычисляет производные параметры и индикаторы, формируя вектор производных параметров в MarketDataEvent

### Сохранение рыночных индикаторов

Сформированные массивы первичных рыночных данных и производных индикаторов сохраняются в Key Value базу данных (Redis или Garnet)
При обновлении ключей в БД по каналу PUB/SUB подписчикам приходит уведомление об обновлении данных.
